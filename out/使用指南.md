# Jev Ultrafast 使用指南

> Jev Ultrafast 是 browser-use 团队开源的极简浏览器 Agent：给定一个自然语言目标，TypeSafe Jev 从动态索引的动作空间中选择操作和元素，仅在需要输入文本时调用一个小型 LLM 生成字段值。

## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| 操作系统 | macOS / Windows / Linux（渲染脚本有 macOS 限制，见第 7 节） |
| Python | ≥ 3.12（建议用 [uv](https://docs.astral.sh/uv/) 管理，仓库自带 uv.lock） |
| 浏览器 | 本机安装的 Chrome / Chromium（允许远程调试，首次连接会提示授权） |
| API Key | `TYPESAFE_API_KEY`（必需）；`TEXT_MODEL_API_KEY`（目标涉及文本输入时必需） |
| Node.js | 仅开发校验时需要（`node --check`） |

## 2. 安装

```bash
git clone https://github.com/browser-use/jev-ultrafast.git
cd jev-ultrafast
uv sync                       # 创建 .venv 并安装 browser-harness、httpx 等
cp .env.example .env          # 然后编辑 .env 填入两个 API Key
```

`.env.example` 内容：

```ini
TYPESAFE_API_KEY=                       # 必需：TypeSafe 操作/目标选择
TYPESAFE_MODEL=jev-latest               # 可选：覆盖模型
TEXT_MODEL_API_KEY=                     # TYPE_TEXT 必需
TEXT_MODEL_BASE_URL=https://openrouter.ai/api/v1
TEXT_MODEL=inception/mercury-2.5
TEXT_MODEL_REASONING=none
```

文本助手是任意 OpenAI 兼容接口：默认 DeepSeek（`https://api.deepseek.com/v1` / `deepseek-chat`），示例配置为 OpenRouter Mercury；Gemini、GLM、DeepSeek 均可，配好 base URL / 模型名 / reasoning 开关即可。

浏览器连接异常时运行 `uv run browser-harness --doctor` 重新连接；Chrome 提示时允许远程调试。

## 3. 快速开始：本地检查器（推荐）

```bash
uv run jev
```

打开 **http://127.0.0.1:8766**（仅回环可访问，端口可用 `TYPESAFE_DEMO_PORT` 修改）：

1. 选择场景：`flights`（真实 Google Flights）或 `travel`/`research`（本地夹具，不花钱）。
2. 输入 1–2000 字符的目标，点 **Start demo**。
3. 点 **Run automatically** 全自动运行；检查器显示编号元素、操作概率、目标概率与已执行动作。
4. **Choose next** 模式会在每次执行前暂停，便于逐步观察决策。

检查器强制单步串行（并发请求返回 409）；出错后按提示 **Reset** 恢复，不会自动重试浏览器变更。

## 4. 库方式使用

### 4.1 基本用法（examples/run.py 模式）

```python
from jev_ultrafast import Agent

with Agent(
    "https://www.google.com/travel/flights?hl=en",
    "Find one-way flights from Zurich to London on September 20, 2026, "
    "for one adult in economy. Stop when matching flight options are visible.",
) as agent:
    for state in agent.run():
        print(state["elapsed_ms"], state["status"])
```

命令行版（`--goal` 可重复传入有序多目标）：

```bash
uv run --env-file .env python examples/run.py \
  --url https://en.wikipedia.org/wiki/Main_Page \
  --goal 'Find and open the Wikipedia article about Gödel's incompleteness theorems.'
```

### 4.2 Agent 构造参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `url` | 必填 | 起始页面 |
| `goals` | 必填 | 字符串或字符串列表（多目标按序拼接）；空目标抛错 |
| `record_dir` | None | 传入路径则每步落一张 JPG 截图（隐含开启截图） |
| `screenshots` | False | 快照附带 base64 截图；库调用默认关闭（模型不消费截图，仅检查器/录制需要） |

### 4.3 手动步进（demo.py 即基于此）

```python
agent.command("reset"...)   # demo 层命令；库层直接构造 Agent
agent.command("predict", {})            # 一次 TypeSafe 决策
agent.command("act", {"fingerprint": agent.state["page"]["fingerprint"]})  # 执行该决策
agent.command("tick", {})               # predict + act 一体
agent.snapshot()                        # 只读状态（含 elements 索引表）
agent.close()
```

`state` 字典要点：`status`（ready/predicted/done/blocked）、`history`（每步动作详情）、`decisions`（每次模型决策）、`text_calls`（每次真实文本生成）、`elapsed_ms`、`page`（url/title/text/actions/fingerprint）。

### 4.4 运行边界（内置预算）

- 最多 **60** 个浏览器动作、**120** 次决策请求，超出即停。
- 连续 3 步页面无变化（且非 WAIT）→ `blocked`。
- `status` 到达 done/blocked 后再发命令会报错；重新 `Agent(...)` 开新运行。

## 5. 真实 Google Flights 演示（含独立校验）

```bash
uv run --env-file .env python examples/flights.py --keep-open
```

- 执行苏黎世→伦敦 2026-09-20 单程经济舱搜索；**只搜索、不选不订**。
- 结束后独立校验最终页面（单程设置、出发/到达城市、日期、结果可见、URL 中的日期），校验失败以非零码退出。
- 产物：`artifacts/flights/latest/state.json`（全量 trace）与 `session.json`；`--keep-open` 保留浏览器标签页。
- ⚠️ 会调用付费 API。

## 6. 本地冒烟 / 守卫检查（不调模型 API）

```bash
# 检查器服务须在另一终端先跑起来（uv run jev）
uv run python scripts/smoke.py            # 本地 travel 夹具端到端（会调付费模型 API）

uv run python scripts/check_guards.py     # 纯本地浏览器守卫回归，零模型调用：
# 覆盖移动目标点击、视口外文本不失效、各类变更失效、遮挡拦截、
# 原生下拉选择、真实文本替换、combobox 建议等待、导航失效
```

## 7. 测量与录制脚本（付费 / 有平台限制）

| 脚本 | 用途 | 备注 |
| --- | --- | --- |
| `scripts/measure_flights.py --output DIR` | 单次实测计时（冻结源码对比版本用） | 付费 API |
| `scripts/record_flights.py <folder>` | 实测 + CDP 连续录屏，保留原始时间戳 | 付费 API |

## 8. 开发与质量检查

```bash
uv run ruff check .                        # lint（line-length 120，规则 E/F/I）
uv run pytest                              # 离线测试，不调付费 API
node --check jev_ultrafast/static/app.js   # 前端语法检查
node --check jev_ultrafast/snapshot.js
uv build                                   # 构建 wheel/sdist
```

约定（摘自 AGENTS.md）：保持循环精简（page → 索引元素 → 操作+目标 → 执行）；不添加站点特定计划或硬编码字段值；绝不重试浏览器变更；凭据留在 `.env`（已 gitignore）；`DONE` 不等于成功，须独立校验结果。

## 9. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `TYPE_TEXT needs TEXT_MODEL_API_KEY` | 目标包含文本输入且未配文本模型 Key；代码不会替你猜值 |
| `Model provider returned HTTP ...; no action executed` | 模型侧错误；循环从不带副作用重试，修正后重新运行 |
| `Page changed since the decision` | 页面在决策后变化（StalePage）；tick 会自动重观察，手动模式重新 predict |
| `Reached the demo's model-call budget` | 120 次决策上限；缩小目标或重新开始 |
| Chrome 未连接 | `uv run browser-harness --doctor`；允许远程调试 |
| 渲染脚本 `OSError: cannot open resource` | macOS 字体硬编码，Windows 需修改字体路径（详见《Windows兼容性分析.md》） |
| 复杂页面无进展 | Shadow DOM/iframe/canvas/上传/弹窗/嵌套滚动不在 MVP 支持范围（docs/design.md 边界） |
