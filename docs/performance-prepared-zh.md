# 一次真实速度的真实航班搜索

> 中文译本 · 原文：[performance-prepared.md](performance-prepared.md)。技术术语保留英文。

**在 Google Flights 上 12.884 秒。** 苏黎世 → 伦敦，单程，2026 年 9 月 20 日周日，一名成人，经济舱。历史预置录制（主演示此后已被替换）· [机器可读证据](flights-prepared-measurement.json)。

| 录制运行 | 测量值 |
| --- | ---: |
| Agent 墙钟时间 | 12,884 ms |
| Jev 请求 | 17 |
| 浏览器动作 | 11：10 次交互 + 1 次等待 |
| 模型请求内部耗时 | 3,050 ms |
| 文本生成调用 | 0 |
| 捕获的录屏帧 | 81 |
| 回放速度 | 1× |

计时从第一次预测开始（在初始 Google Flights 首页观察之后），到最终的 DONE 选择结束。它包括模型调用、浏览器执行、观察、截图、异步的 Google 加载，以及页面变化时被丢弃的决策。浏览器启动、初始导航和设置都在计时之外。视频加了 750 ms 片头停顿和 2 秒片尾停顿；计时运行本身未剪辑、未加速。

agent 从通用的 Google Flights 首页开始，代码没有预填任何航线/日期查询。每一个目标都由 Jev 选出。五个显式有序的子目标指定行程；这不是自主行程规划。Zurich 和 London 从目标里带引号的值中复制而来，因此这些计时不包含可选的文本模型。可选的 GLM 辅助在本地夹具上单独演练过。

## 校验了什么

一个独立谓词检查了结果搜索页、单程设置、出发地苏黎世、目的地伦敦、出发日期显示、从页面价格追踪文本中读取的年份，以及 9 月 20 日真实航班结果的标签。捕获的页面包括：

- easyJet：ZRH → LGW，16:45–17:35，直飞，$216。
- 英国航空 / BA Cityflyer：ZRH → LCY，20:25–21:00，直飞，$265。
- SWISS：ZRH → LGW，17:10–17:50，直飞，$370。

价格是本次运行期间观察到的，可能发生变化。搜索还返回了其他结果；这并不是声称这些是最便宜的可用票价。没有选择或预订任何航班。

## 开发尝试

| 尝试 | 结果 | Agent 时间 | 改动 |
| --- | --- | ---: | --- |
| 1 | 航线/日期/结果校验通过 | 14.118 s | 逐节点 DOM 读取 |
| 2 | 航线/日期/结果校验通过 | 14.162 s | 批量布局提取 |
| 3 | 失败 | 1.585 s | 放宽的新鲜度让一个菜单动画状态到达了模型；它选择了 BLOCKED |
| 4 | 航线/日期/结果校验通过并录制 | 12.884 s | 恢复严格新鲜度；显式的动画/等待指引 |

这些是在改动过代码、浏览器缓存和真实站点响应下的迭代开发尝试。它们不是对照性能比较，也不是可靠性估计。失败的新鲜度改动已被移除。一次成功的公开工作流不构成通用浏览器基准。

## 更早的夹具基线

人工编写的酒店夹具在三次运行中以 **1,086 / 1,242 / 1,311 ms** 完成五个动作，每次运行六个 Jev 调用。那个更小的状态和本地页面省去了真实站点的加载成本。这些数字保留在 [measurement.json](measurement.json) 中，并非 Google Flights 的结果。另一次使用 GLM 生成文本的夹具运行耗时 4,650 ms。
