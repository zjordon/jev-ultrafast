# 在真实网络上更快

> 中文译本 · 原文：[performance.md](performance.md)。技术术语（Jev、TypeSafe、Mercury、TYPE_TEXT、WAIT、DONE、BLOCKED 等）保留英文。

当前视频以 **1× 速度在 7.073 秒内**完成 Google Flights 任务。它从一个自然语言目标开始，全程使用动态控件。Jev 在一次请求中选出操作 + 目标；当 TYPE_TEXT 被选中时，由 Mercury 生成城市字符串。

[视频](demo.mp4) · [录制测量数据](flights-measurement.json) · [对照运行测量数据](full-speed-measurement.json)

## 对照运行时比较

六次交替运行，同一任务，同一个现有 Chrome 配置文件。两组使用相同的自然语言目标、独立的结果校验器、1120×780 视口、TypeSafe `jev-1.13.0`、`inception/mercury-2.5`、禁用文本推理，以及相同的动作/请求预算。两组均排除初始导航。每次运行创建并关闭自己的标签页。六次尝试全部计入；未发生服务商或校验失败。

| 配对 | 原始运行时 | 优化后运行时 | 已验证 |
| --- | ---: | ---: | --- |
| 1 | 11.214 s | 6.964 s | 两者均通过 |
| 2 | 8.984 s | 7.913 s | 两者均通过 |
| 3 | 9.450 s | 7.092 s | 两者均通过 |
| **中位数** | **9.450 s** | **7.092 s** | **各 3/3 通过** |

优化后运行时在三对中全部更快。中位任务时间**降低 25.0%**，中位 TypeSafe 请求数从 **22 降至 17**，中位浏览器协议调用从 **1,092 降至 101**。三对样本太少，不足以构成强统计断言（双侧符号检验 p = 0.25）。这是一次小规模的受控输入对照，不是广泛的 agent 基准测试；Google、网络响应、路由和浏览器缓存都保持实时。

原始组是冻结自 `68c077bf79caca4e817b8e8a5854b2efa0c81ff6` 的源码。两组都使用 Mercury，因此该运行时对照不会把辅助模型的更换与代码改动混为一谈。每次运行的源码哈希、模型设置、token 数量、辅助调用成本、浏览器版本、协议调用计数与校验结果都记录在测量 JSON 中。

## 时间都花在哪

原始循环在每次 DOM 变更（包括动画）时都使决策失效。它还反复读取无障碍树并解析数百个 DOM 节点。新快照在一次浏览器调用中读取常见 HTML/ARIA 控件。点击守卫比对被选目标及其邻近上下文，外加文档/表单状态。输入前仍然执行即时几何解析与命中测试。

一个基于事件的简短 combobox 等待，让建议项在 Jev 从不完整的弹层中挑选之前先到达。文本来自真实的 LLM：录制运行生成 **Zurich 用了 581 ms**，**London 用了 346 ms**。原生文本替换也被修正为显式发出浏览器的全选命令。

录制包含 **17 次 Jev 请求**、**10 次交互外加 1 次显式 WAIT**、**2 次辅助调用**。Jev 中位延迟为 **178 ms**。搜索在 **5.217 s** 时执行；最终通过校验的完成时刻是 **7.073 s**。最后这段间隔包含 Google 结果加载、状态变化和完成决策。它保留在视频中。

计时从首页初始观察后的第一次预测开始，到被接受的 DONE 选择结束。它包括文本生成、模型请求、浏览器工作、失效决策和加载等待。浏览器启动、初始导航，以及运行之后全新的独立校验都在计时之外。视频包含 186 帧连续录屏帧加上初始截图，使用原始时间戳，没有片头停顿，只加了 0.5 秒片尾停顿。仅裁掉了顶部的账户/导航条。

录制报告所有请求共消耗 90,558 个 TypeSafe 输入 token 和 6,325 个输出 token。OpenRouter 报告两次文本调用花费 **$0.00006272**。这只是文本辅助调用的费用，不是任务总成本：TypeSafe 响应只含 token 计数、没有美元账单金额，浏览器成本也不计入其中。

## 其他检查

| 任务 | 耗时 | 独立结果 |
| --- | ---: | --- |
| Wikipedia：打开哥德尔不完备定理条目 | 2.798 s | 精确的文章 URL |
| 本地酒店夹具：搜索里斯本、Design、免费取消，打开 Casa Flora | 1.896 s | 房源加上三个已应用的筛选条件 |

这些是独立的冒烟检查，不是对照速度比较。本地浏览器检查覆盖被移动/替换/隐藏/禁用的控件、字段与复选框属性、邻近上下文变化、遮挡拦截、原生下拉执行、真实文本替换、自动补全到达和页面导航。离线测试覆盖模型契约、stale 重试、被中断的变更、辅助校验，以及独立的行程校验。

在计时运行之后，原生下拉的中断处理被收紧：结果不确定的变更直接停止，而不再被当作可重试的 stale 读取。Flights 任务不会触发原生 SELECT。它的时间与录制哈希保持不变；最终失败路径由离线故障注入和本地浏览器检查覆盖。

## 保留的开发尝试

在冻结候选版本之前，原始运行时曾以 9.302 s 通过一次。两个无障碍树/语义守卫候选分别用了 9.395 s 和 10.157 s。第一个直连 DOM 候选用了 8.697 s，但因名称/值提取不完整而未通过独立校验。递归 label 解析和 combobox 取值修复了该失败；随后通过校验的诊断耗时 8.051、8.631、8.395、8.385 和 7.741 s。一次 Mercury 诊断以 7.559 s 通过。这些是改动过代码的开发尝试，不是上面的对照比较。

一次六调用的辅助探测，用两个真实航班字段上下文测试了 Gemini 2.5 Flash Lite、Gemini 3.1 Flash Lite 和 Mercury 2.5。在这个极小的探测中它们都返回了正确值。随后 Mercury 通过了实时 Flights、Wikipedia 和本地筛选检查。这不能确立普遍的语义准确性。更早的探测曾淘汰过两个模型：一个颠倒了出发地/目的地，另一个输出的是评论而非合法 JSON。

此前 11.387 秒的录制以及录制后 12.898 秒的策略回归，记录在[原始性能报告](https://github.com/browser-use/jev-ultrafast/blob/68c077bf79caca4e817b8e8a5854b2efa0c81ff6/docs/performance.md)中。更早的预置步骤原型保留在 [performance-prepared.md](performance-prepared.md)（[中文](performance-prepared-zh.md)）。原始尝试与原始时间戳帧保留在被 git 忽略的本地 artifacts 中。

## 局限

这个 DOM 读取器支持常见的 HTML 和 ARIA 控件；它没有实现完整的可访问名称算法，也不遍历 shadow root/iframe。作用域化的点击守卫有意允许无关的可见更新。Canvas、文件上传、新标签页、嵌套滚动和任意键盘组件仍不支持。一个合法的操作仍然可能是错的，DONE 也永远不是成功的独立证据。
