## `浏览器执行与输入前守卫` 方法逻辑梳理

### 📋 **方法作用**

把动作真正送进 Chrome：`Browser.act` 做输入前最后一道新鲜度守卫，`browser_operation` 的 act 分支按动作类型执行——全部路径**零重试**，几何与命中测试在输入瞬间重新解析。

> 源码: agent.py 第 116-117 行（调用点）+ browser.py 第 100-107 行（`Browser.act`）、第 120-194 行（`browser_operation`）

---

### 🔄 **主要逻辑流程**

#### **1️⃣ 输入前守卫（browser.py 第 100-107 行）**

```python
def act(self, action, page, text=None):
    if not self.fresh(page, action):
        raise StalePage("Page changed since this decision. Observe again.")
    if action["kind"] == "wait":
        time.sleep(0.1)
    result = browser_operation({"operation": "act", "session": self.session, "action": action, "text": text})
    self.after_input = action if action["kind"] != "wait" else None
    return result
```

- click/select 用**动作级守卫**（page_key + guard）；fill/scroll 用全页 marker。
- `after_input` 记录刚执行的动作——下一次 observe 据此决定等待策略（Phase 3 消费）。
- 测试 `test_executor_rejects_a_stale_page_before_browser_input`：fresh=False → StalePage 且 `browser_operation` 未被调用。

#### **2️⃣ scroll 与 wait（browser_operation 第 135-139 行）**

```python
if kind == "scroll":
    call("Input.dispatchMouseEvent", type="mouseWheel", x=550, y=650, deltaX=0, deltaY=action["delta"])
```

- 固定视口中心滚 ±560px；wait 在上层已 sleep(0.1)。

#### **3️⃣ 目标解析（第 141-160 行，页面内求值）**

```python
if type(action["node"]) is not int:
    raise ValueError("Invalid observed node")           # 节点 id 必须是代码所有整数
target = evaluate("""(action => {
  const e=window.__jevFast?.nodes.get(action.node);     // 身份表取回真实节点
  if (!e?.isConnected || e.matches(':disabled') || e.closest('[aria-disabled="true"],[inert]') ||
      !e.checkVisibility(...)) return null;             // 可见/可用复查
  if (action.kind==='fill' && (e.readOnly || aria-readonly)) return null;
  const r=e.getBoundingClientRect(), x=r.x+r.width/2, y=r.y+r.height/2;   // 即时几何
  if (!r.width || !r.height || x<0 || y<0 || x>=innerWidth || y>=innerHeight) return null;
  if (!e.contains(document.elementFromPoint(x,y))) return null;           // 命中/遮挡测试
  if (action.kind==='select') { 校验 option → e.value=... → input+change 事件 }
  return {x,y};
})""")
```

**✅ 有效**：返回中心坐标（select 已在此完成设值）。
**❌ 无效**（None）：
```python
if kind == "select":
    raise RuntimeError("Dropdown execution was not confirmed; inspect before retrying.")
raise StalePage("Target changed or is covered. Observe again.")
```
- select 的执行在求值中**可能已部分完成**（change 事件已发）→ RuntimeError 强制人工检查而非重试。

#### **4️⃣ 输入派发（第 165-185 行）**

```python
for event in ("mousePressed", "mouseReleased"):
    call("Input.dispatchMouseEvent", type=event, x=x, y=y, button="left", clickCount=1)
if kind == "fill":
    # selectAll（macOS Cmd=4 / 其他 Ctrl=2）→ insertText
    call("Input.dispatchKeyEvent", type="keyDown", key="a", code="KeyA",
         modifiers=4 if sys.platform == "darwin" else 2, commands=["selectAll"])
    call("Input.dispatchKeyEvent", type="keyUp", ...)
    call("Input.insertText", text=request["text"])
```

- fill 显式全选后插入——**替换**既有内容（旧版依赖隐式全选曾出 bug，performance.md 记载修复）。

#### **5️⃣ 求值中断处理（第 127-133 行）**

```python
if result.get("exceptionDetails"):
    if operation == "act" and request["action"]["kind"] == "select":
        raise RuntimeError("Dropdown execution was interrupted; inspect before retrying.")
    raise StalePage("Document changed during evaluation")
```

- 导航销毁求值上下文：click/fill 判为 StalePage（输入尚未发生，重观察安全）；select 因变更可能已触发，判 RuntimeError。

---

### 🎯 **设计亮点**

1. **几何永远即时**：决策时的 rect 只用于可见性筛选；点击坐标在输入瞬间重取——动画移动的目标点新位置，不触发重新预测（check_guards.py 首项回归）。
2. **遮挡测试**：全屏覆盖层挡住按钮 → `elementFromPoint` 不命中 → 拒绝输入（语义不变但物理不可点）。
3. **变更结果三态**：成功 / StalePage（未变更，可重观察）/ RuntimeError（可能已变更，必须停）。
4. **代码所有的节点引用**：`nodes.get(action.node)` 只接受 snapshot 分配的整数；模型无从构造选择器。

---

### 📊 **返回值结构**

`{"executed": action["id"]}`（agent.py 不消费其内容，仅依赖无异常即成功）；副作用 = 页面输入 + `after_input` 标记。

---

### 💡 **典型使用场景**

- Flights：点开 combobox、点日历日期、点 Search 按钮、输入城市名——全部经此单一路径。

---

### 🔗 **与其他方法的协作**

```
command('act')
  └─▶ Browser.act
        ├─ Browser.fresh(page, action)   ← 动作级守卫
        └─ browser_operation(act)
              ├─ 页面内目标解析（nodes.get → 几何 → 命中）
              ├─ CDP Input.* 派发
              └─ (成功) → Phase 3 写前日志
                    (StalePage) → Phase 4 tick 恢复
```
