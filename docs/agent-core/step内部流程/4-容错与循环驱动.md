## 📋 Phase 4 — 容错与循环驱动（tick/run）概述

> 入口: `Agent.command('tick')`（agent.py 第 55-64 行）与 `Agent.run()`（第 163-165 行）。
> 一句话：tick 把 predict+act 组装成带 StalePage 兜底恢复的单步；run 是生成器外壳，按 status 决定循环生死。

### 🔄 主要逻辑流程

#### 1️⃣ **tick 编排与 StalePage 恢复** (agent.py 第 55-64 行)
```python
if name == "tick":
    try:
        self.command("predict", {})
        return self.command("act", {"fingerprint": state["page"]["fingerprint"]})
    except StalePage:
        state["decision"] = None
        state["status"] = "ready"
        state["page"] = state["browser"].observe(screenshot=self.screenshots)
        state["elapsed_ms"] = round((time.perf_counter() - state["started_at"]) * 1000)
        return self.snapshot()
```
- 正常路径：predict → act（指纹直传，杜绝中间篡改）。
- 恢复路径：清决策 → 回 ready → 重观察——**恢复=重看，不是重做**。

#### 2️⃣ **run 生成器与终止条件** (agent.py 第 163-165 行)
```python
def run(self):
    while self.state["status"] not in {"done", "blocked"}:
        yield self.command("tick")
```
- 六种终止来源汇聚于 status 两个终态（详见详档对照表）。

### 🔄 数据流

```
调用方（for state in agent.run() / 检查器）
  │
  ├── 子步骤1 → snapshot（正常步）或 snapshot（恢复步）
  └── 子步骤2 → yield 逐帧输出；status ∈ {done, blocked} 时停止
```

## 返回值

每 tick 一个 snapshot dict；生成器在终态后自然耗尽。

## 总结

1. 🛡️ StalePage 是唯一的自动恢复异常，且恢复动作是只读的。
2. 🔁 循环驱动极薄——所有业务不变量都在 predict/act 内，tick 只做组合与兜底。
3. ⏸️ 暂停语义=调用方停止迭代（生成器天然支持）。
