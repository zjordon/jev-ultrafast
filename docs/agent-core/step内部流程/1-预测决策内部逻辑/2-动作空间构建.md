## `动作空间构建（action_space）` 方法逻辑梳理

### 📋 **方法作用**

把 snapshot.js 产出的扁平动作列表重组为模型可选择的动态动作空间：**每个 DOM 节点一个索引**的元素表、每种操作各自合法的目标组、不可寻址的控制动作——这是"模型做选择题"的选项生成器。

> 源码: model.py 第 48-78 行

---

### 🔄 **主要逻辑流程**

#### **1️⃣ 分类（第 51-56 行）**

```python
operations = {"click": "CLICK", "fill": "TYPE_TEXT", "select": "SELECT"}
for action in actions:
    kind = action["kind"]
    if kind not in operations:
        controls[action["id"].upper()] = action   # wait / scroll_down / scroll_up
        continue
```

- 三种可寻址操作 + 不可寻址控制动作二分。

#### **2️⃣ 一节点一索引（第 57-66 行）**

```python
node = action["node"]
if node not in indices:
    index = str(len(elements) + 1)
    indices[node] = index
    element = {k: action[k] for k in ("role", "value", "checked", "selected", "expanded") if k in action}
    element.update(index=index, label=action["label"].split(" → ")[0], operations=[])
```

- 同一节点第二次出现（fill + click）复用索引；label 去掉 ` → 选项` 后缀还原字段名。
- select 元素初始化 `options: []`，值取 `current_value`（当前已选项）。

#### **3️⃣ 目标登记（第 67-78 行）**

```python
target = index
if kind == "select":
    target = f"{index}:{len(element['options']) + 1}"
    element["options"].append({"index": target, "label": action["label"], "value": action["value"]})
group[target] = action
```

- click/fill 目标 = 索引；select 目标 = `"index:option序号"` 复合索引（代码拥有选项序号，模型只挑）。
- 元素的 `operations` 列表按首次出现顺序累积（如 `["TYPE_TEXT", "CLICK"]`）。

---

### 🎯 **设计亮点**

1. **一节点一索引**：combobox 的"输入"与"点开"共享索引，目标头内不重复计数；索引即人机共同的元素语言（README 元素表与检查器直接展示）。
2. **选项即目标**：原生下拉的每个 option 是独立目标——模型选的是"字段 3 的第 2 项"，不是自由文本。
3. **动态即全部**：空间每次观察重建，无预置动作模板，天然适配任意站点（AGENTS.md：不加站点特定计划）。

---

### 📊 **返回值结构**

| 字段 | 类型 | 说明 |
|------|------|------|
| `elements` | `list[dict]` | `{index, label, role, value, checked?, selected?, expanded?, operations, options?}` |
| `targets` | `dict[str, dict[str, action]]` | 键如 `CLICK`/`TYPE_TEXT`/`SELECT`，仅含该操作合法目标 |
| `controls` | `dict[str, action]` | `WAIT`/`SCROLL_UP`/`SCROLL_DOWN` |

---

### 💡 **典型使用场景**

- `choose()` 每次决策前重建（model.py 第 82 行）。
- `Agent.snapshot()` 取 `[0]` 供检查器渲染元素表（agent.py 第 49 行）。

### 🔗 **与其他方法的协作**

```
snapshot.js actions
  │
  ▼
action_space
  ├── elements ──────────▶ TypeSafe state（模型可见）
  ├── targets ───────────▶ 各目标头 criteria（候选集合）
  └── controls ──────────▶ operation 头候选
```
