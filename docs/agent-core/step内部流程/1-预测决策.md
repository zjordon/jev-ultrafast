## 📋 Phase 1 — 预测决策（predict）概述

> 入口: `Agent.command('predict')`（agent.py 第 65-85 行），由 tick 或检查器调用。
> 一句话：把"当前页面 + 目标 + 历史"变成**一次**经过严格校验的 TypeSafe 决策（操作 + 目标），存入 `state['decision']` 并落账。

### 🔄 主要逻辑流程

#### 1️⃣ **前置校验与新鲜度检查** (agent.py 第 66-76 行)
```python
if not state["browser"]:
    raise ValueError("Start a demo first")
if state["started_at"] is None:
    state["started_at"] = time.perf_counter()
if not state["browser"].fresh(state["page"]):
    state["page"] = state["browser"].observe(screenshot=self.screenshots)
...
if len(state["decisions"]) >= MAX_STEPS * 2:
    raise ValueError("Reached the demo's model-call budget")
```
- 会话存在性 → 计时零点 → 页面新鲜度（不新鲜先重观察）→ 终态/预算拒绝。

#### 2️⃣ **动作空间构建** (model.py 第 48-78 行 `action_space`)
```python
node = action["node"]
if node not in indices:
    index = str(len(elements) + 1)
```
- snapshot 的扁平动作 → 「一节点一索引」元素表 + 各操作专属目标组 + 控制动作；select 目标为 `index:option` 复合索引。

#### 3️⃣ **TypeSafe 请求构建与发送** (model.py 第 81-119 行 + 第 15-27 行 `post_json`)
```python
questions[operation.lower() + "_target"] = {
    "type": "choice", "criteria": {...}, "instructions": {"goal": goal, "operation": operation, "rules": [NEXT_ACTION, TARGET]}
}
```
- 组装 operation 头 + 每操作一个目标头（同规则、同目标、互不知答案）→ 一次 `POST /v1/systemone`（429/529/503 退避重试 ≤3）。

#### 4️⃣ **多头响应校验与决策落账** (model.py 第 120-148 行 + 第 30-45 行 `validate_choice` + agent.py 第 77-85 行)
```python
target_answer = validate_choice(result["answers"].get(operation.lower() + "_target", {}), targets[operation])
```
- 只校验被选操作的目标头 → choice 映射回动作 id → 决策连同 fingerprint/耗时记入 `decisions` → `status='predicted'`。

### 🔄 数据流

```
page(观察态) + goal + history[-10:]
  │
  ├── 子步骤1 → 新鲜的 page（必要时重观察）
  ├── 子步骤2 → elements / targets / controls
  ├── 子步骤3 → HTTP 响应 answers（概率分布）
  └── 子步骤4 → state['decision']（choice/operation/target/...）
                + state['decisions'].append（账本）
```

## 返回值

`command('predict')` 返回 `self.snapshot()`；关键副作用是 `state['decision']` 非空、`status='predicted'`、`decisions` 追加一条。

## 总结

1. 🔍 两道预算：120 次决策（此处）+ 60 个动作（act 处）。
2. 🎯 一次往返定操作与目标——投机头无效答案不可能执行。
3. 📊 决策账本自带 fingerprint 与 latency_ms，可完整审计。
